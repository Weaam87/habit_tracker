# Habit Tracker

## App Details
- **Name:** Habit Tracker
- **Short Description:** A mobile and web app that helps you create, manage, and complete daily habits with colorful visual feedback.
- **Full Description:**
  Habit Tracker empowers users to build consistent routines by making it easy to create personalized habits, organize them with color coding, and celebrate progress. The app remembers your profile details, synchronizes habit lists locally for quick access, and offers intuitive swipe gestures to mark activities as complete or undo them. A built-in notification setup screen lets you plan reminders, while detailed reports highlight completed tasks to keep motivation high across devices.
